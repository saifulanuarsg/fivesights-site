If something fails

Phones stop following: dot at bottom right is red; switch laptop to the hotspot.
A phone is stuck: pull down to refresh; their work is kept.
Engine fails: each pair of tables picks one interview from their phones as its persona.
No slides link: the table pitches from its prototype.
Everything down: backup deck on Drive, run on paper.
